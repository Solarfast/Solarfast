The heated-area dropdown uses its rounded midpoint only as an estimate and identifies it in the form, result details, and PDF. Annual gas use is an exact user-entered value; do not bucket it or substitute a midpoint. If reopening an older session that stored a gas-range midpoint, clear it and ask for the actual value.

**Why:** Gas use is a direct input to the financial comparison. A bucket midpoint is not the user's meter/bill reading and must not be presented or used as exact consumption.

**How to apply:** Keep the area-range estimate disclosure aligned across standalone and combined flows, results, and reports. Preserve the exact gas value through validation, saved sessions, calculations, results, and reports.

Use the energy label together with the explicit roof, cavity-wall, floor, and glazing answers to refine the existing preliminary insulation band. Air-conditioning is not a water-based emitter: do not infer low-temperature hydronic distribution or fully-electric suitability from it, and retain an installer-review warning.

**Why:** These answers should affect the existing preliminary recommendation without making an air-to-water model appear compatible with a home's current air-only heat delivery.

**How to apply:** Preserve the distinction in advice logic, results, and PDF output; keep the sizing disclaimer and require the user to identify unknown insulation details explicitly.
