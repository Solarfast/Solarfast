---
name: Battery backup recommendation
description: Product rule for backup power in the SolarFast battery-selection flow
---

When a customer requests backup power, recommend a HYXiPower All-in-One only after the customer confirms a 3-phase connection. If 1-phase is selected, pause the backup recommendation and ask for confirmation; never auto-upgrade the phase or assume compatibility from another model or manual entry.

**Why:** The user explicitly chose customer confirmation first for 1-phase plus backup. Silent phase switching or unverified model compatibility could misstate the household wiring or backup capability.

**How to apply:** Treat backup as an explicit requirement, keep other brands available for comparison, and allow continuation only after a compatible catalog product is selected or the customer turns backup off.
