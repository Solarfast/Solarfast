## FIX 1 — Terugverdientijd bug (server.py)

Pas VOLTRAX/backend/server.py aan.

Zoek:
```python
    payback_low  = (battery_price / total_annual_high) if total_annual_high > 0 else 99.0
    payback_high = (battery_price / total_annual_low)  if total_annual_low  > 0 else 99.0
    payback_low  = max(3.5, payback_low)
```

```python
    payback_low  = (battery_price / total_annual_high) if total_annual_high > 0 else 99.0
```
