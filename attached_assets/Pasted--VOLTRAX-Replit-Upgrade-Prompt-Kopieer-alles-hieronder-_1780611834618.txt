## WIJZIGING 1 — Backend: Dynamisch contract (server.py)

Voeg `dynamic_contract` toe aan `CalculationInput`:

```python
dynamic_contract: Optional[bool] = False
```

Pas `calculate_battery_savings` aan met extra parameter `dynamic_contract: bool = False`.

Vervang in STAP 4 de constanten:

```python
if dynamic_contract:
    EMS_GRID_CYCLES      = 336   # 280 × 1.20
    EMS_MAX_SOLAR_CYCLES = 180
    EMS_MAX_TOTAL_CYCLES = 480   # 400 × 1.20
    SPREAD_LOW           = 0.28
    SPREAD_HIGH          = 0.34
else:
    EMS_GRID_CYCLES      = 280
    EMS_MAX_SOLAR_CYCLES = 180
    EMS_MAX_TOTAL_CYCLES = 400
    SPREAD_LOW           = 0.20
    SPREAD_HIGH          = 0.26

ems_annual_low  = bat_kWh * ems_cycles * SPREAD_LOW
ems_annual_high = bat_kWh * ems_cycles * SPREAD_HIGH
```

Voeg toe aan de return dict:
```python
"ems_solar_cycles": round(ems_solar_cycles, 0),
"ems_total_cycles": round(ems_cycles, 0),
"spread_low":       round(SPREAD_LOW, 2),
"spread_high":      round(SPREAD_HIGH, 2),
"dynamic_contract": dynamic_contract,
```

Voeg deze velden ook toe aan `CalculationResult` als Optional fields.

Pas de `/calculate` endpoint aan zodat `dynamic_contract` wordt doorgegeven:

```python

    ...bestaande parameters...,
    dynamic_contract=input_data.dynamic_contract or False,
```
