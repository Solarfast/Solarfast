## STAP 3 — Voeg batterij-efficiëntie toe

Zoek:

```python
ems_solar_cycles = min(EMS_MAX_SOLAR_CYCLES, shifted_kwh / bat_kWh) if bat_kWh > 0 else 0.0
ems_cycles       = min(EMS_MAX_TOTAL_CYCLES, ems_solar_cycles + EMS_GRID_CYCLES)

ems_annual_high = bat_kWh * ems_cycles * SPREAD_HIGH
```

Vervang met:

```python
BATTERY_EFFICIENCY = 0.95  # LFP round-trip efficiency
```

## TECHNISCHE ONDERBOUWING

- 95% round-trip efficiency is representatief voor moderne LFP thuisbatterijen.
- Dynamische spreads van €0,25–€0,32 per kWh sluiten aan bij gangbare EPEX-spreads in Nederland.
- 320 EMS-dagen modelleren een conservatief aantal rendabele spread-dagen binnen een gemiddeld dynamisch contract.
- Uplift 1.08–1.12 fungeert als praktijkcorrectie voor EMS-optimalisatie, seizoenseffecten en marktvariatie.
