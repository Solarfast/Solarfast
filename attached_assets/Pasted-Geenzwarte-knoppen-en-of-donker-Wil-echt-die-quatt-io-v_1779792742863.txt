⚙️ 1. CORE PRINCIPLE
Het systeem simuleert geen “gemiddelde gebruiker”, maar:

Dit betekent:
* batterij laadt uitsluitend overschot PV

* minimale export, maximale zelfconsumptie
* dynamische prijsverschillen worden benut

⚙️ 3. ENERGIEBALANS (HARD RULE — BELANGRIJK)
Alle berekeningen moeten voldoen aan:
* PV = self-consumption + export
* Verbruik = self-consumption + import
* Batterij kan alleen overschot PV verschuiven (geen extra energie creëren)
* Geen negatieve energie flows toegestaan
 
⸻
 
🔋 4. BATTERIJ MODEL (SCHAALBAAR + NIET LINEAIR)
4.1 Overshoot bepalen
overschot = PV - baseline self-consumption
baseline self-consumption = 35% van PV
 
⸻
 
4.2 Batterij effect (DIMINISHING RETURNS)
Gebruik niet-lineaire curve:
utilisation_factor = 1 - exp(-(battery_kWh / PV_kWh) * 2.2)
 
⸻
 
4.3 Self-consumption met batterij
self_consumption_rate =
min(0.92, 0.35 + (0.57 * utilisation_factor))
👉 verklaard:
* 0.35 = baseline
* max uplift = +57%
* cap = 92%
 
⸻
 
⚡ 5. PRIJSMODEL (REALISTISCH MAAR OPTIMAL)
Gebruik 3 waardes:
* self-consumed kWh = €0.30
* exported kWh = €0.07
* imported kWh = €0.30
 
⸻
 
BATTERIJ ARBITRAGE UPLIFT (GEEN FIXED GETAL)

price_spread = €0.30 - €0.07
